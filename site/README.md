# Markovskiy Games website

Static website prepared for GitHub Pages. The public entry point is `index.html`, which opens the main dark site in `dark.html`.

## Publish with GitHub Pages

1. Create a GitHub repository for the site.
2. Upload the contents of this `site` folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, then choose the branch containing these files and the `/ (root)` folder.
5. Save and wait for GitHub to show the public URL.

## Before public launch

- Replace the temporary studio name if a different brand name is chosen.
- Set the accent colour once in `assets/css/skins/yellow.css` or switch the linked skin in `dark.html`.
- After GitHub Pages provides the final URL, add it as the canonical and Open Graph URL in `dark.html`.
- Add an absolute Open Graph image URL after the public address is known, so shared links have a branded preview.
- Add a studio email to the Contact section.
- Confirm every portfolio role, external link and publication permission.
- Create a separate, verified privacy-policy page for every game that is released.

The project-by-project publication checklist is in `CONTENT_REGISTRY.md`.

Do not publish a generic privacy policy without confirming the game's data collection, advertising, analytics and third-party SDKs.
